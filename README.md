# (C# 코딩) 에코 메신저

## 개요
- C# 프로그래밍 학습
- 1줄 소개: 사용자의 키보드 입력으로 받은 텍스트를 리스트에 출력하는 간단한 메신저 프로그램
- 사용한 플랫폼:
	- C#, .NET Windows Forms, Visual Studio, GitHub
- 사용한 컨트롤:
	- Label, TextBox, Button, ListBox
- 사용한 기술과 구현한 기능:
	- Visual Studio 디자이너를 활용한 UI 구성
	- string 클래스를 이용한 사용자 입력 데이터 처리
	- Trim(), IsNullOrWhiteSpace()를 이용한 입력값 정제 및 공백 입력 방지
	- DateTime 클래스를 이용한 현재 시간 정보 생성 및 타임스탬프 출력
	= 이벤트 기반 프로그래밍(Button Click, KeyDown)을 통한 사용자 입력 처리
